## Environment limitation

A complete Docker image build and frontend dependency installation could not be executed in the audit environment because the npm registry connection repeatedly timed out and no Docker daemon is available. GitHub Actions now performs both checks on every push and pull request. The frontend source and Docker configuration were inspected manually in addition to the automated backend checks.
