# Bekannte Grenzen von DocOfHome 1.3.0

- Passive Schrankkomponenten besitzen derzeit keine einzeln nummerierten
  Anschlussklemmen. Ein- und Abgänge werden über Verbindungen und die optionale
  Zahl der Abgänge dokumentiert.
- Drag-and-drop ist für Schutzgeräte auf Desktop-Geräten vorgesehen. Auf
  Touchgeräten bleibt der Positionsdialog der verlässliche Bedienweg.
- Schrankkomponenten werden über den Dialog positioniert und noch nicht selbst
  per Drag-and-drop verschoben.
- DocOfHome besitzt weiterhin keine Benutzerverwaltung und darf nur in einem
  vertrauenswürdigen privaten Netzwerk betrieben werden.
