# Bekannte Grenzen DocOfHome 1.4.0

- Die Sammelschiene modelliert eine wiederholte Phasenfolge über TE, aber keine
  einzelnen nummerierten Zähne oder Klemmen.
- Die Zahl der Abgänge einer Schrankkomponente bleibt eine Information und wird
  nicht als harte Anschlussgrenze erzwungen.
- N-Schienen werden einer FI-Gruppe als Ganzes zugeordnet; einzelne
  Neutralleiterklemmen werden nicht verwaltet.
- Die Phasenermittlung setzt voraus, dass die dokumentierte Startposition und
  TE-Breite der tatsächlichen Montage entsprechen.
- Automatische Zuordnungen sind Plausibilitätsunterstützung für zuhause und
  ersetzen keine Prüfung der Anlage durch eine Elektrofachkraft.
- Touch-Geräte verwenden für präzises Verschieben weiterhin den
  Positionierungsdialog statt ausschließlich Drag-and-drop.
